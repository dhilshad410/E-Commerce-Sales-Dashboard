E-Commerce Sales & Customer Insights Dashboard

Project Overview

This project presents an interactive E-Commerce Sales Dashboard created using Microsoft Excel. It helps analyze sales performance, customer insights, product performance, payment methods, and order status.

Tools & Technologies

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Slicers
- Timeline
- KPI Cards

Dataset Information

- Total Records: 51,290
- Total Columns: 25
- Data Type: Synthetic practice dataset
- Domain: E-Commerce Sales

Note: This dataset was created for learning and dashboard development purposes. It does not represent actual business transactions.

Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders
- Total Customers
- Products Sold
- Average Order Value
- Total Returns

Dashboard Features

- Monthly Sales Trend
- Region-wise Sales Performance
- Category-wise Sales Distribution
- Payment Method Analysis
- Order Status Analysis
- Top 10 Best-Selling Products
- Interactive Slicers and Timeline

Project Objectives

- Analyze e-commerce sales performance.
- Identify top-performing regions and products.
- Understand customer and payment trends.
- Create an interactive dashboard for business insights.

Conclusion

This project demonstrates the use of Microsoft Excel for data cleaning, data analysis, visualization, and interactive dashboard development.
